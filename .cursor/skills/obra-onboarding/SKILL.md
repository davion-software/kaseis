# Obra onboarding

## Promise

An obra usable in ~48 hours for a suitable ICP: catalog, users, baseline inventory, WhatsApp flows ready.

## Steps

1. Diagnosis map (materials, roles, sources)
2. Organization + project + locations
3. Catalog load (Excel/CSV) — aliases, units, packaging, minimums; human review before activate
4. Users + Kapso phone linkage
5. Approved initial count
6. 20–30 min training per role
7. Accompaniment cadence

## Implementation notes

- Templates owned by worksites/inventory modules
- Use `xlsx` skill for spreadsheet templates
- Do not require the customer to design the whole process alone
- Expand to more obras only after the first is stable

See `/onboard-obra` command and `docs/product/pilot-scope.md`.
