# Architecture decision record

Create a new ADR under `docs/decisions/`.

## Steps

1. List existing files in `docs/decisions/` and pick the next number `NNN`.
2. Write `docs/decisions/NNN-short-title.md` with Status, Date, Context, Decision, Consequences.
3. If the decision changes stack or auth, update `AGENTS.md` / relevant rules.
4. Keep it short; link to overview docs instead of duplicating.

## Template

```markdown
# ADR NNN — Title

- **Status:** Accepted | Proposed | Superseded
- **Date:** YYYY-MM-DD

## Context
## Decision
## Consequences
```
