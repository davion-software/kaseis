# Onboard obra (48h)

Run or update the assisted obra onboarding checklist.

## Checklist

1. Diagnosis: critical materials, roles, current Excel/cuaderno sources
2. Create organization + project + locations
3. Import/review catalog (aliases, units, packaging, minimums)
4. Users + WhatsApp numbers linked via Kapso
5. Approved initial physical count (baseline)
6. Short training per role
7. Daily then weekly review cadence

Update `docs/` or runbooks if the process changes. Apply skill `obra-onboarding`. Use Anthropic `xlsx` skill when handling Excel templates.
