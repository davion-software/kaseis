# Architecture decision record

Create a new ADR under `docs/adr/`.

## Steps

1. List existing files in `docs/adr/` and pick the next number `NNNN`.
2. Write `docs/adr/NNNN_TITLE.md` with Status, Date, Context, Decision, Consequences.
3. If the decision changes stack or auth, update `AGENTS.md` / relevant rules.
4. Keep it short; link to overview docs instead of duplicating.

## Template

```markdown
# ADR NNNN — Title

- **Status:** Accepted | Proposed | Superseded
- **Date:** YYYY-MM-DD

## Context
## Decision
## Consequences
```

Preserve accepted decision history. Mark superseded records and link their replacements rather than rewriting their rationale.
